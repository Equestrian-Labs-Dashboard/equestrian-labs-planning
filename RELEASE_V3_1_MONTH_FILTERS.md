# v3.1 — Actuals Month Filters

- Corro Month filter starts at Jan 2026; no 2025 options.
- Cavali Month filter starts at the current month and automatically advances as new months are loaded.
- The month filters control Baseline / Current actuals only.
- The 2026 Full-Year Forecast still uses closed YTD actuals + remaining-month forecast, so selecting one month cannot accidentally distort the FCS.
- Refresh Actuals repopulates month options from Shopify data and preserves a valid selection.
- Draft/Budget/Forecast/Board save the selected source month independently with the existing scenario state.
